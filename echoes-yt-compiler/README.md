# TikTok → YouTube compiler

Turns Brandon's TikTok speeches into YouTube videos without copyright problems:

1. **Long-form compilation** (`compile.py` + `plan.json`): 16:9 frame with the vertical clip over a blurred copy of itself, exposure lift for dark clips, punch-in zooms, word-by-word captions, chapter titles, cold open, title card and end screen. Also writes YouTube chapters and an `.srt`.
2. **Cinematic music video** (`music_video/`): selected spoken lines on a 70 BPM bar grid (`timeline.py`), a score generated in code (`score.py`), and a 2.39:1 letterboxed edit with colour grades, kinetic type, dust/light-leak layers and a shaking drop (`visuals.py`).
3. **Thriller cut** (`music_video/thriller_audio.py` + `thriller.py`): the same timeline with synthesised sound design (trailer hits, reverse swells, a Shepard-tone riser, heartbeat, breath, glass shatter, chains, tinnitus with a muffled score after the drop), a low double on the darkest lines, bleach-bypass/red/sepia grades, title cards on black, key-word eye close-ups, glitch hits synced to the SFX and film subtitles in the letterbox bar.
4. **Thumbnails** (`thumbnail.py`).

Everything you hear is either Brandon's own voice (TikTok "original sound") or audio generated by `make_assets.py` / `music_video/score.py`. TikTok library music is deliberately left out: its licence does not carry over to YouTube, so those clips would get Content ID claims.

## Setup
```bash
pip install yt-dlp curl_cffi faster-whisper imageio-ffmpeg numpy scipy pillow "opencv-python-headless<5"
export FFMPEG=$(python3 -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())")
export WORK=/path/to/workdir      # holds clips/, transcripts/, assets/, fonts/
```
Fonts (OFL, from github.com/google/fonts): Anton, Archivo Black, Cinzel Decorative Bold/Black and PT Sans (subtitles) → `$WORK/fonts/`.

## Steps
```bash
# 1. clean (no watermark) copies of your videos; your own-sound ones are the YouTube-safe ones
yt-dlp --impersonate chrome -f "b[format_id!=download]" --write-info-json -o "$WORK/clips/%(id)s.%(ext)s" <video urls>
# 2. transcripts with word timings (see transcribe step in the session notes: faster-whisper small.en, word_timestamps=True)
# 3. assets
cd $WORK && python3 /path/to/make_assets.py
# 4. long-form video (edit plan.json to choose clips, in/out phrases, chapter names, caption fixes)
python3 compile.py plan.json                   # RESUME=1 keeps finished segments, ONLY=3,4 renders just those
python3 thumbnail.py $WORK/clips/<id>.mp4 67.75 "STOP" "DIGGING." thumb.jpg
# 5. music video
python3 music_video/timeline.py && python3 music_video/score.py && python3 music_video/visuals.py
# 6. thriller cut (needs timeline + score from step 5)
python3 music_video/thriller_audio.py && python3 music_video/thriller.py
```

Note: TikTok only serves the no-watermark stream at 576x1024 (~214 kbps). If you still have the original
phone recordings (1080x1920), drop those into `clips/` under the same ids: the whole pipeline gets sharper for free.

`youtube_upload.md` has the title, description, tags and settings for Vol. 1.
