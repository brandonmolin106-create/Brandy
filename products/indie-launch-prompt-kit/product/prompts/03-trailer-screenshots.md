# 03 · Trailer and screenshots (10 prompts)

### 3.1 30-second trailer script
```
Act as a trailer editor for indie games and apps. Write a 30-second trailer script for {{PRODUCT}}: a table with columns Time, Shot (what's on screen), Text overlay (under 6 words), Sound. Rules: the hook is on screen by second 2, no logo before second 25, one text overlay per shot, end on the store name and price. Add a 6-second cut-down for social at the end.
```

### 3.2 Shot list
```
Act as a producer. From the brief and the trailer script, list every shot I need to capture: shot number, what to show, duration, capture settings (resolution, fps, UI on/off), and the single thing that must be visible in frame. Group by scene so I capture them in one session.
```

### 3.3 GIF moments
```
Act as a social editor. List the 8 most satisfying 3–6 second moments in {{PRODUCT}} to capture as GIFs, ranked by how well they show {{HOOK}} with no sound and no context. For each: what happens, where to start and stop, and the caption under 8 words.
```

### 3.4 Screenshot plan
```
Act as a store-page designer. Plan 6 screenshots for {{PRODUCT}} that tell a story: hook, depth, variety, progression, polish, social proof or scale. For each: what's on screen, what to crop out, caption, and whether it needs a text overlay. Specify the platform's required sizes for {{PLATFORMS}}.
```

### 3.5 Thumbnail text
```
Act as a thumbnail designer. Write 10 options for the text on {{PRODUCT}}'s thumbnail or capsule image: max 3 words, readable at 100 px wide, no punctuation. Say which 2 to A/B test and what background each needs.
```

### 3.6 Trailer voiceover
```
Act as a VO scriptwriter. Write a 30-second voiceover for {{PRODUCT}} in the voice {{VOICE}}: 70–80 words, first line is the hook, one sentence of what you do, one sentence of what's inside, close with the platform and price. Mark breaths with "/". Then write a 12-word version for a 6-second cut.
```

### 3.7 Music brief
```
Act as a music supervisor. Write a brief for the trailer music for {{PRODUCT}}: genre, tempo range, mood in 3 words, where the drop should land (second), what to avoid, and 5 search phrases for a royalty-free library. Add a one-line prompt for an AI music tool if I'd rather generate it.
```

### 3.8 Trailer critique
```
Act as a trailer editor. I'll describe my trailer shot by shot with timestamps. Tell me: where the hook actually appears, every second that could be cut, any text that fights the picture, and the 3 changes that would most improve click-through. Return a revised shot table.
```

### 3.9 Vertical cut
```
Act as a short-form editor. Convert the trailer script into a 15-second vertical (9:16) cut for X, TikTok and Shorts: what to crop, which 3 shots survive, on-screen text per shot under 5 words, and the first-frame text that stops the scroll.
```

### 3.10 Press kit assets list
```
Act as a PR assistant. List every asset the press kit for {{PRODUCT}} needs with exact specs: logo (formats, sizes), key art, 6 screenshots, 3 GIFs, trailer link, fact sheet fields, bio, contact. Write the fact sheet now from the brief.
```
