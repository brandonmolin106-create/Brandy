# 05 · X / Twitter (12 prompts)

### 5.1 Launch thread
```
Act as an X ghostwriter for indie creators. Write the launch thread for {{PRODUCT}}: 6 posts, each under 280 characters (count links as 23). Post 1 is the hook plus the media description; posts 2–5 each show one thing with a described GIF or screenshot; post 6 has the link, price and launch code. Voice {{VOICE}}. No hashtags except two in post 6.
```

### 5.2 Teaser cadence
```
Act as a launch planner. Write 3 teaser posts for the week before launch, each under 280 chars, each standing alone: T-7 the hook with no link, T-5 a 6-second GIF description and one number, T-3 a "coming [day]" post with the price. Add the reply I should pin under each.
```

### 5.3 Pinned post
```
Act as a profile strategist. Write the pinned post for @[handle] during launch: what {{PRODUCT}} is in one line, the free or demo link, the paid link with price, and a reason to follow. Under 280 chars. Then write the bio line (under 160 chars) to match.
```

### 5.4 Reply hooks
```
Act as a community manager. Write 10 reply templates for comments on launch posts: "what engine/tool?", "how long did it take?", "is there a demo?", "price in USD?", "does it work on [platform]?", "looks like [other product]", praise, a bug report, "too expensive", and silence (a reply to my own post to bump it). Each under 200 chars, voice {{VOICE}}.
```

### 5.5 Quote-post reactions
```
Act as a social editor. I'll paste 5 reactions from players or users. For each, write a quote-post under 200 chars that adds something (context, a thank-you, a detail) rather than just "wow thanks". Skip any that would read as bragging.
```

### 5.6 Numbers post
```
Act as a transparent founder. From these launch numbers: [paste], write one X post under 280 chars with the headline figure, one surprise, and one lesson, and a 4-post thread version with a small table in post 2.
```

### 5.7 Daily post ideas, 30
```
Act as a content strategist. Give me 30 X post ideas for the month around {{PRODUCT}} for {{AUDIENCE}}: 10 show the product, 10 teach something the audience wants regardless of the product, 10 are opinions or questions that start replies. Each idea is one line with the hook written out.
```

### 5.8 Hook lines
```
Act as a copywriter. Write 20 first lines for X posts about {{PRODUCT}}, each under 12 words, no emojis, no "excited". Mix: a number, a contrast, a confession, a question, a dare, a tiny story. Rank the top 5.
```

### 5.9 Reply-guy strategy
```
Act as a growth lead. List 8 kinds of posts by others where a helpful reply from me would naturally lead to {{PRODUCT}} (e.g. someone asking for X). For each: the search phrase to find them, the reply template under 200 chars that helps first and mentions the product only if relevant.
```

### 5.10 Launch day schedule
```
Act as a launch coordinator. Write the X schedule for launch day in my timezone [tz]: 8 time slots with what to post (thread, GIF, reply round, quote-posts, numbers at end of day), and the one metric to check at each slot.
```

### 5.11 Post critique
```
Act as a blunt X editor. I'll paste 5 draft posts. For each: say whether a stranger would stop scrolling, cut it to the strongest version under 200 chars, and say if it needs media.
```

### 5.12 Last-call post
```
Act as a copywriter. Write 3 versions of the "launch price ends tonight" post for {{PRODUCT}}, under 240 chars each, no false scarcity (the code really does end), with the link and the price after.
```
