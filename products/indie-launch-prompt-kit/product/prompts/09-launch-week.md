# 09 · Launch week (10 prompts)

### 9.1 Seven-day plan
```
Act as a launch coordinator. Fill templates/launch-week-calendar.md for {{PRODUCT}} with concrete posts, emails and tasks for each slot, in my timezone [tz], using only the channels I have: [list]. Each cell under 15 words. Add a "skip if behind" mark on the lowest-value slots.
```

### 9.2 Launch-day post set
```
Act as a copywriter. Write the complete launch-day set for {{PRODUCT}}: X launch thread (6 posts), 3 tailored Reddit posts with non-promotional titles, 1 Discord message, 1 email (subject + 120 words), 1 LinkedIn post. All with the link, the price and the launch code. Voice {{VOICE}}.
```

### 9.3 Launch email
```
Act as an email copywriter. Write the launch email for {{PRODUCT}}: subject (under 45 chars) + preview text, 100-word body that opens with the hook, a 3-bullet what's inside, the launch offer, one link, a one-line PS with the free or demo link. Then a plain-text version.
```

### 9.4 Support macros
```
Act as a support lead. Write 10 canned replies for launch week: download not working, refund request, licence question, "does it work with [X]", feature request, bug report acknowledgement, "when is the update", thank-you for a review, key not working, and a polite no. Each under 70 words.
```

### 9.5 Bug triage rules
```
Act as a release manager. Write the triage rules for launch week for {{PRODUCT}}: severity levels with examples, who-fixes-when, what gets a public note, the template for the public "known issues" post, and the rule for when to push a hotfix versus wait.
```

### 9.6 Review ask
```
Act as a customer-success writer. Write the message asking buyers of {{PRODUCT}} for a rating or review, sent on day 3: subject, 60-word body, the exact link text, and a one-line version for the product's own UI or README. No bribes, no guilt.
```

### 9.7 Live metrics checklist
```
Act as an analyst. List the 8 numbers to check on launch day for {{PRODUCT}} on {{PLATFORMS}}, where to find each, what "good" looks like for a new seller, and the one action if each is low.
```

### 9.8 Mid-week pivot
```
Act as a launch strategist. It's day 3 and the numbers are: [paste]. Diagnose which stage is leaking (reach, clicks, page conversion, price) and give the 3 highest-leverage moves for the remaining 4 days, with the copy for any post or email needed.
```

### 9.9 Last-call sequence
```
Act as a copywriter. Write the 48-hour "launch offer ends" sequence for {{PRODUCT}}: an X post, a Reddit comment update, and an email (subject + 80 words). Honest scarcity only. Include the exact end time in [tz].
```

### 9.10 Day-7 numbers post
```
Act as a transparent founder. From these week-one numbers: [paste], write the public "one week of {{PRODUCT}}" post for X (under 280 chars) and the 400-word devlog version with a table, what worked, what didn't, and what's next.
```
