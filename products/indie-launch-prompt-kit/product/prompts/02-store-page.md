# 02 · Store page (12 prompts)

### 2.1 Full store page draft
```
Act as a conversion copywriter for indie products. Using the brief and templates/store-page-template.md section order, write the complete store page for {{PRODUCT}} for {{PLATFORMS}}: headline, sub-headline, three proof points, 150-word body, "what you get" bullets (nouns first), FAQ (price, refunds, platform, updates, licence), closing line and button text with the price. Voice: {{VOICE}}. No claims without a fact behind them.
```

### 2.2 Gumroad description, HTML
```
Act as a Gumroad seller. Turn the store page into a Gumroad description in clean HTML: <p> and <ul> only, bold the first sentence, bullets for what's included, a "Try it first" line if a free version exists, a 30-day guarantee line, and a launch-code line. Under 300 words. Output the HTML only.
```

### 2.3 Steam short + about
```
Act as a Steam page specialist. Write the Steam short description (under 300 characters, hook first) and the "About this game" section (3 paragraphs, each starting with a bold 4–6 word feature line) for {{PRODUCT}}. End with a 5-bullet feature list. Include one sentence on length/replayability and one on accessibility options if any.
```

### 2.4 itch.io page
```
Act as an itch.io seller. Write the itch page for {{PRODUCT}}: a 2-sentence intro, controls block, "what's in the free version / full version" table, a 4-item FAQ, and the exact text for the "Buy now" button and the pay-what-you-want suggested price line. Keep it under 250 words; itch readers skim.
```

### 2.5 App Store / Play listing
```
Act as an ASO writer. For {{PRODUCT}}, write: app name (30 chars), subtitle (30 chars), promotional text (170 chars), description (first 3 lines must stand alone, 4 short paragraphs total), and 10 keyword phrases ranked by search intent for {{AUDIENCE}}. No competitor names.
```

### 2.6 What-you-get bullets
```
Act as an editor who hates fluff. Write the "What you get" list for {{PRODUCT}}: 6–8 bullets, each starting with a noun and a number where one exists, under 12 words, no adjectives. Then write a one-line "What it is not" to pre-empt refunds.
```

### 2.7 FAQ generator
```
Act as a support lead. Write 8 FAQ entries for {{PRODUCT}} covering: what it is, platform/compatibility, how to install or use, what the free version includes, licence and commercial use, updates, refunds, and the question {{AUDIENCE}} asks that most sellers forget. Answers under 40 words, plain, no hedging.
```

### 2.8 Screenshot captions
```
Act as a store-page designer. I'll paste descriptions of 5–8 screenshots. For each, write a caption under 8 words that names the benefit shown, not the UI element, and suggest an order that tells a story from hook to depth.
```

### 2.9 Guarantee and licence block
```
Act as a plain-language legal writer. Write a 3-sentence money-back guarantee and a 5-line personal-use licence for {{PRODUCT}} ({{TYPE}}) suitable for a store page footer. Cover: what buyers may do, what they may not, team size, updates, refund window.
```

### 2.10 Page critique
```
Act as a conversion reviewer. I'll paste my store page. Score it 1–10 on: hook clarity in the first 2 lines, proof density, scannability, objection coverage, call-to-action strength. For every score under 8, quote the exact words at fault and rewrite them. Return the fully revised page.
```

### 2.11 Short description variants
```
Act as a copywriter. Write 6 short descriptions for {{PRODUCT}} under 160 characters each, for platform cards and link previews. Each must contain the type, the hook and the audience. Mark the best one for search and the best one for social.
```

### 2.12 Localisation brief
```
Act as a localisation manager. For {{PRODUCT}}'s store page, list the 6 lines that must be translated first for a launch in Spanish, Portuguese, German, Japanese and Simplified Chinese, the idioms in my copy that won't translate, and plain-English rewrites of those lines. Keep the hook intact.
```
