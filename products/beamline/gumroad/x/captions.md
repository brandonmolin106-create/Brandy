# Post 2 — feature
Every Beamline level is built backwards from a known solution, then rejected if it can be solved with zero mirrors. So all 40 are solvable and none are trivial.

Try the free 20: https://htmlpreview.github.io/?https://raw.githubusercontent.com/brandonmolin106-create/Brandy/claude/gracious-archimedes-tk01xr/products/beamline/build/free/index.html
