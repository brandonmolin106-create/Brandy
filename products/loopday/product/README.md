# LoopDay Pro — routines & habit tracker

One file. Open it in any browser and it works. No account, no subscription, no server. Your data stays on your device.

## Install

**Phone (iPhone / Android)**
1. Put `LoopDay.html` somewhere you can open it: email it to yourself, AirDrop it, or drop it in iCloud Drive / Google Drive / Files.
2. Open it in Safari (iPhone) or Chrome (Android).
3. Share → **Add to Home Screen**. It opens full-screen like an app and works offline.

**Computer**
Double-click `LoopDay.html`. Bookmark it. That's it.

**Keep it in one place.** Your data is stored by the browser for that file's location, so open it from the same spot every time. Export a backup (Settings → Export JSON) before moving the file or switching devices, then Import on the new one.

## What it does

- **Habits**: name, icon, which days of the week. Tap to check off. Streak counter, best streak, and a 12-week heat map per habit.
- **Routines**: an ordered list of timed steps (morning reset, workout circuit, wind-down). Press Start and LoopDay counts each step down with a chime between steps and keeps the screen awake. Completed routines are logged.
- **Today**: everything due today with a completion ring.
- **Stats**: check-ins, best streak, routines done, last-7-days bars, per-habit numbers.
- **Settings**: light/dark/system theme, week start day, sound on/off, export/import JSON, reset.

Pro is unlimited habits and routines plus export/import. The free web version is capped at 3 habits and 1 routine.

## Example data

First launch shows three example habits and one example routine so you can see how it looks. Edit or delete them, or Settings → Reset all data to start clean.
