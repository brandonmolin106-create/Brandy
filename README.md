# Echoes in the Dark

## TMNT Turtle Power: Story Mode (Minecraft Java 1.20.1, Forge)

A fan-made story mode where **you are Raphael**: the lair, the sewers (ladders + manhole covers),
a chunk of New York City, Leo/Donnie/Mikey as teammates who defend you, the Kraang, mutagen,
text-to-speech dialogue and a five chapter story.

**Downloads** are in [`download/`](download):

| File | What it is |
|---|---|
| `TMNT-Story-Mode-CurseForge.zip` | **Everything in one file** (Forge + mod + world). CurseForge app → Create Custom Profile → Import. |
| `TMNT-Story-Mode.mrpack` | Same thing for the Modrinth App / Prism Launcher. |
| `turtlepower-1.0.0.jar` | Just the mod (goes in `.minecraft/mods`, needs Forge 1.20.1). |
| `TMNT-Story-Mode-World.zip` | Just the pre-built world (unzip into `.minecraft/saves`). |

Full guide, story walkthrough and commands: [`tmnt-story-mode/README.md`](tmnt-story-mode/README.md).
