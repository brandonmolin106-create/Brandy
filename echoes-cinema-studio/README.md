# Echoes in the Dark — Cinema Studio (realistic thriller cut)

The no-particles version of **"The Fish in the Cup"**: path-traced CG (Blender Cycles, CPU) intercut with
Brandon's own performance footage treated as a confession tape, a thriller grade, hit-synced typography and a
new synthesized score under his original voice.

```
blender/   scene + shot code (runs inside Blender 4.5)
  betta.py            procedural halfmoon betta: lofted body, 5 fin membranes, eyes, per-frame swim rig
  betta_textures.py   scale / fin-ray / ragged-edge texture generator (numpy + OpenCV)
  props.py            glass cup + animated water, walnut table, pendant lamp, blinds, materials
  sets.py             render setup + the interrogation room
  shots.py            cup-set shots (macro, glass hit, flare, lift, loops, stills)
  ocean.py            underwater shots (cup sinks, fish set free, vast ocean, ghost cup)
  world.py            storm sea, sunrise, lone tree, pet-store shelf, Earth, galaxy
  run_shot.py / run_any.py / render_queue*.sh   resumable frame rendering
comp/      compositor (numpy/OpenCV)
  edl.py              the cut: every shot, slam, flash and impact timed to the words
  cinema.py           EDL -> 1080x1920 @ 24 fps frames -> H.264 chunks
  fx.py               grade, halation, bloom, god rays, grain, CA, glitch, shadows, bell jar, cracks
  typo.py             slams, counters, typewriter, red-keyword captions, brand / end card
  face_frames.py      reframes the TikTok source around its burned-in caption and black bands
audio/
  thriller_audio.py   voice bus + drone / pulse / heartbeat / clocks / braams / impacts / ambiences, -14 LUFS
```

## Pipeline

```bash
# 1. textures + renders (Blender 4.5 LTS)
python blender/betta_textures.py /opt/assets/betta
blender/render_queue.sh  $WORK/cine/renders fish_macro_turn cup_side_loop ...   # cup set
blender/render_queue2.sh $WORK/cine/renders                                      # ocean / world / space
# 2. picture + sound
python comp/face_frames.py $WORK/<video>.mp4 $WORK/cine/face
python audio/thriller_audio.py $WORK $WORK/cine/audio/thriller_mix.wav
comp/assemble.sh $WORK/cine OUTDIR
```

Render budget on the 4-core CPU box: 540x960 at 8 spp + OpenImageDenoise (~12 s/frame for glass + water +
fish, 3-8 s for the open-world shots), upscaled 2x in the compositor. Slow shots are rendered on every second
frame and blended.
